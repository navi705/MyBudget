# Gemini Workflow

This document outlines the development workflow for the Gemini assistant.

## Development Process

1.  **Write Code:** Implement a new feature or fix a bug.
2.  **Write Test:** Write a test that covers the new code.
3.  **Repeat:** Repeat steps 1 and 2 for approximately 3-5 related changes.
4.  **Run Tests:** Run the full test suite to ensure that all changes are working correctly and that no regressions have been introduced.
