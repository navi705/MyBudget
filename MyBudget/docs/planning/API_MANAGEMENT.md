## Background Task & Windows Isolate

В Flutter на Windows существует баг Dart VM (связанный с FFI/SQLite), из-за которого использование `compute()` (отдельного изолята) при старте может привести к ошибке `unreachable code` и краху приложения.

**Наше решение:**
Вместо `compute` мы используем асинхронный вызов функции `_fetchApiDataInIsolate` в основном изоляте, но **без ожидания (`await`)**. 
- Это позволяет коду выполняться асинхронно ("в фоне"), не блокируя отрисовку UI.
- Пользователь сразу видит Dashboard, а данные подгружаются параллельно.
- Код архитектурно готов к возврату в `compute`, как только баг в Flutter будет исправлен.

### URL Handling
Можно использовать как полные URL (`https://api.com/data`), так и "голые" IP-адреса или хосты (`192.168.1.10`, `localhost:8080`). 
Если протокол (`http://` или `https://`) не указан, приложение автоматически добавит `http://`.

## Форматы данных для Custom API

Для корректного импорта ваш сервер должен возвращать JSON в одном из следующих форматов:

### 1. Курсы валют (Exchange Rates)
**URL DataType:** `0` (или `exchange_rates`)
```json
{
  "type": "exchange_rates",
  "data": [
    {
      "date": "2026-01-22",
      "from": "EUR", 
      "to": "USD",
      "rate": 1.085
    }
  ]
}
```

### 2. Инфляция (Inflation)
**URL DataType:** `1` (или `inflation`)
```json
{
  "type": "inflation",
  "data": [
    {
      "date": "2026-01-01",
      "country": "SRB",
      "rate": 0.5
    }
  ]
}
```

### 3. Цены активов (Asset Prices)
**URL DataType:** `2` (или `assets`)

Поля объекта (Fields):
*   `date` (Required): Формат `YYYY-MM-DD`
*   `code` (Required): Тикер актива (например, `AAPL`)
*   `name` (Optional): Название актива (например, `Apple Inc.`). Если не указано, используется `code`.
*   `value` (Required): Цена
*   `currency` (Optional): Валюта цены (например, `USD`). Если не указано, по умолчанию `EUR`.

Пример:
```json
{
  "type": "assets",
  "data": [
    {
      "date": "2026-01-22",
      "code": "AAPL",
      "name": "Apple Inc.",
      "currency": "USD",
      "value": 185.50
    }
  ]
}
```
