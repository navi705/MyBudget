# Идея проекта: MyBudget

## Концепция

Создание мультиплатформенного, гибкого и мощного приложения для отслеживания личных финансов. Проект будет развиваться как Open Source решение.

## Основные функции

*   **Учет доходов и расходов:**
    *   Запись и редактирование транзакций.
    *   **Древовидные категории:** Возможность создавать вложенные категории (например, `Транспорт -> Такси`) для детальной аналитики.
    *   Поддержка нескольких валют.
*   **Управление счетами и долгами:**
    *   Отслеживание баланса на разных счетах.
    *   Учет долговых обязательств.
*   **Финансовые цели:**
    *   Создание конкретных, измеримых целей (например, "На машину", "Отпуск").
    *   Отслеживание прогресса по каждой цели.
    *   Прогнозирование даты достижения цели на основе текущего темпа накоплений.

## Ключевые принципы и архитектура

*   **Open Source:** Проект будет полностью открытым, что способствует доверию и позволяет сообществу участвовать в разработке.
*   **Гибкость и кастомизация:**
    *   **Интерфейс:** Возможность смены тем (светлая/темная), а в будущем и наборов иконок.
    *   **Данные:** Архитектура на плагинах для подключения разных источников данных (API, локальные файлы).
*   **Прогрессивное раскрытие (Gradual UI):**
    *   Интерфейс по умолчанию будет простым для начинающих.
    *   Продвинутые функции (аналитика, прогнозы) будут доступны опционально, не перегружая основной экран.
*   **Полный контроль над данными:**
    *   Возможность легкого импорта и экспорта данных в различных форматах (CSV, JSON и др.). Пользователь — единственный владелец своих данных.
*   **Исторический анализ стоимости денег:**
    *   Встроенная функция для учета инфляции при анализе финансов, позволяющая оценивать реальную стоимость денег во времени.
*   **Продвинутое прогнозирование и моделирование:**
    *   **Моделирование инвестиций:** Инструменты для прогнозирования роста капитала с учетом различных типов инвестиций (недвижимость, акции, вклады) и их ожидаемой доходности.
    *   **Временные срезы:** Возможность просмотра прогнозов в годовом и месячном разрезе.
    *   **Исторические снимки прогнозов:** Система будет сохранять "снимки" прогнозов. Это позволит в будущем сравнивать "что прогнозировалось" с "что получилось по факту", анализируя точность планирования.
*   **Гибкая синхронизация данных:**
    *   Пользователь сам выбирает, как хранить и синхронизировать свои данные, исходя из своих потребностей в удобстве или приватности.
    *   **Облачный режим:** Удобный вариант, где данные хранятся на сервере и доступны с любого устройства.
    *   **Локальный режим (Self-Host):** Возможность запустить серверную часть на своем оборудовании для полного контроля.
    *   **P2P режим (без сервера):** Возможность прямой синхронизации данных между своими устройствами без какого-либо центрального сервера для максимальной конфиденциальности.

## Платформы

*   **Приоритетные платформы (MVP):**
    *   Веб-версия.
    *   Настольное приложение (Windows).
    *   Мобильное приложение (Android).

## Планы на будущее

*   **Расширение поддержки платформ:** Добавление поддержки macOS, Linux и iOS.
*   **Продвинутая автоматизация:** Разработка (вероятно, в виде плагинов) функций для автоматического импорта транзакций, например, через чтение SMS или API банков.
